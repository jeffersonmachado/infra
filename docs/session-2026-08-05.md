# Sessão 2026-08-05 — Recuperação do Webmail

## Evento

Webmail `https://www.results.com.br/webmail/` fora do ar com erro de
certificado SSL (`ERR_CERT_AUTHORITY_INVALID`).

## Causa raiz

O container `secure-httpd` foi recriado às 05:40 UTC e o `mod_md` (Let's
Encrypt) não iniciou a renovação dos certificados automaticamente. Todos os
4 domínios gerenciados (`results.com.br`, `mx1.results.com.br`,
`r-observe.results.com.br`, `ripabx.results.com.br`) estavam no estado
`state=1` ("certificate is missing"), servindo apenas certificados fallback
autoassinados.

## Ações

### 1. Renovação dos certificados SSL

```bash
docker exec secure-httpd httpd -k graceful
```

O graceful restart disparou o `mod_md`, que:
- Criou conta ACME em `md/accounts/ACME-.letsencrypt.org-0000`
- Completou desafios HTTP-01 para `results.com.br` e `www.results.com.br`
- Obteve certificado Let's Encrypt (válido até 2026-11-03)

### 2. Correção do proxy para o Joomla

Após o SSL voltar, o Apache retornava `500 Proxy Error - DNS lookup failure
for: joomla`.

**Causa**: O Apache faz proxy para `http://joomla/` mas o container tem
`container_name: results-joomla`. O DNS embutido do Docker resolve por
`container_name`, não pelo nome do serviço no compose.

**Hotfix aplicado**:
```bash
docker network disconnect infra-shared results-joomla
docker network connect --alias joomla --alias results-joomla infra-shared results-joomla
```

**Correção permanente**: Adicionado `aliases: [joomla]` no
`docker-compose.yml` (serviço `joomla`, seção `networks.default`).

### 3. Validação

- Certificado SSL válido (Let's Encrypt YR1)
- Login no webmail funcional (`jefferson` / `jcm@1970`)
- Caixa de entrada carregando normalmente

## Lições aprendidas

- `mod_md` pode não iniciar renovação automaticamente após restart do
  container; `httpd -k graceful` resolve
- Todo serviço com `container_name` explícito precisa de `aliases` com o
  nome do serviço se outros containers o referenciam pelo service name
- O fallback cert do mod_md tem validade de 14 dias — a janela para
  perceber o problema é curta
